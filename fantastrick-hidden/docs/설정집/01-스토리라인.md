# 1호점 설정집 — 「태초의 신부 : 이브 프로젝트」 스토리라인

> 2026-11-14 정리. 근거 = 매장 비치 스토리북(스토리 1·2) + ADAM 사건보고서(1/2·2/2) + 매장 사진 21장.
> 손님 = **팀 EVE**. 설정집은 EVE 시점이 본문, ADAM 사건보고서는 부록(쫓는 쪽의 기록).
> 이식 대상 = 1호점 히든페이지(`production/`), 구조는 Z-VIRUS(락다운시티) v2.1 입장화면 + story.html 뷰어 방식.

## 액자 구조 (확정 2026-11-14)

- 이야기 전체 = **할아버지가 손자 '카인'에게 들려주는 옛날이야기**.
- **시작**: 아지트에서 옛날이야기를 꺼내는 할아버지(해커 방 노트북의 오프닝 나레이션).
- **본편**: 손님이 그 이야기 속으로 들어가, 젊은 할아버지가 팀 EVE로 태초의 신부를 훔치던 그날을 직접 겪는다.
- **엔딩 영상**: 다시 현재. 할아버지가 손자에게 이야기를 마무리하고, 이때 처음으로 손자 이름 **'카인'**이 나온다.
- 카인 = 성경에서 아담과 하와(EVE)의 아들. EDEN·ADAM·EVE·SNAKE·선악과에 이어지는 이름 체계의 마지막 조각.
- 설정집에서도 **카인이라는 이름은 마지막 장에서 처음 드러낸다**(엔딩과 같은 구조).

## 세계관

- **ADAM Inc.** — 세계적 보안 회사. 성물 **선악과**(코드명 〈태초의 신부〉)를 지킨다.
- **도시 EDEN · 에덴 거리** — 평범한 거리로 위장한 보안 시스템. 실물 구조 = **좁은 돌바닥 길 양쪽으로 가게들이 마주 보는 거리**(가운데 벤치·가로등), 일자 배치 아님(11-14 3D 배치도 확인). 가게 7곳 = 보안장치 7개 = **7대 죄악**.
  7개를 모두 풀어야 **지하 13층 챔버**가 승강기로 지상까지 올라온다.
- **챔버 승강기 = GLUTTONY 가게 가운데 문** (확정 2026-11-14). 보안이 다 풀리면 이 문이 열리고, 지상에 올라온 챔버가 나타난다.
  챔버 = 직사각형 상자 모양의 두꺼운 강철, 엄청 단단해 보임. 실물(사진 11-14): GLUTTONY GROCERY STORE의 갈색 문짝 두 개가 바깥으로 열리고, 안에 둥근 핸들·위쪽 작은 화면(AD 로고)이 달린 은빛 리벳 강철 문. 바로 옆이 PAWN SHOP이라 전당포 벽의 균열로 챔버에 들어간다.
- **선악과 = 성물(聖物)**, 어떤 능력을 가진 성스러운 물건. '태초의 신부'는 별칭, 진짜 이름은 선악과. 물에 반응해 폭발적으로 자란다(아무도 몰랐던 부작용). 파괴가 아니라 **정화·자연화**의 힘.
- 매장에서는 상자에 담아 나무에 매달아 두었지만, **이야기 속에선 나무 가지에서 꽃이 지고 직접 열린다**. 그림도 그렇게 그린다.
- 이름 체계 = 에덴동산: EDEN · ADAM · EVE · SNAKE(뱀) · 선악과 · Apple Tree.

### 7곳 밖의 장소
- **PAWN SHOP (FAST CA$H)** — 보안장치가 아닌 **챔버로 들어가는 통로**. 선악과 반응으로 균열이 생기고, 비상용 총을 얻는 곳.
- **Apple Tree Flower Shop** — 에덴의 나무 상징.
- **챔버** — 금고(SHINIL SAFES)를 뚫고 자란 나무, 붉은 흙, 나무에 매달린 새 선악과.
- **관리센터** — ADAM 직원이 대기하며 원격 관리. 스네이크의 D-Day 당직 장소.

## 인물

- **스네이크** — 정체를 감춘 인물. 오래전부터 ADAM에 잠입. The LUST Bar 담당자가 본사로 파견 간 사이 임시 담당.
  다크웹에서 기술자들을 '테스트'로 고른다.
- **팀 EVE (손님)** — 암흑가 기술자들. 그림에선 **은밀한 전문 도둑**(검은 터틀넥·코트·장갑·비니), 특수부대 차림 금지. 태초의 신부를 조사하던 중 스네이크에게 뽑힌다.
- **당신** — 팀 EVE의 일원이자, 수십 년 뒤 손자에게 이 이야기를 들려주는 화자.
- **조력자** — 엔딩에서 선악과를 넘겨받는 사람(정체 미정).

## 스토리라인 (EVE 시점, 실제 동선 순서)

### 0. 은신처 — 해커 방 (첫 방)
- 팀 EVE가 모여 다크웹에 도는 소문 '태초의 신부'를 조사 중이다.
- 게시판 분위기: "주먹만 한 체리 보석이라던데?", "그거 다 거짓말", "스네이크라는 사람이 연락 왔는데 테스트한다더니 연락이 없다", "태초의 신부 조심하세요".
- 그러다 **스네이크의 초대**가 도착한다 → The LUST Bar로 향한다.

### 1. The LUST Bar · VIP 룸 — 작전 회의
- 목표: EDEN 지하 13층의 선악과.
- 왜 지금인가: EDEN의 1월은 장마철, 올해는 기록적인 폭우와 낙뢰로 대피령. ADAM 직원은 관리센터에서 원격 관리만 한다. 스네이크는 D-Day에 관리센터 당직이다.
- 역할: 스네이크는 관리센터에서 본사의 눈을 막고 원격 지원, 팀 EVE는 거리에서 보안장치를 푼다.
- 프로젝트 이름 = **EVE**.

### 2. 에덴 거리 — 일곱 죄악을 연다
- 보안장치 7개를 순서대로 해제한다(LUST · CODICIA · Envie · GLUTTONY · SLOTH · STOLZ · NEWS STAND).
- 폭우와 낙뢰, 잠깐의 정전과 복구.
- GLUTTONY 가운데 문(챔버 승강기)이 열리고, 지하 13층에서 올라온 직사각형 강철 챔버가 나타난다.

### 3. 계획이 틀어진다 — 전당포
- 챔버 문은 본사와 통신이 연결돼야 열리는데, 낙뢰로 자동 통신 복구가 늦어진다 → 강제로 열어야 한다.
- 하수처리시설을 폭파 → 챔버는 멀쩡하지만 **바로 옆 전당포 안쪽 벽돌벽이 무너지고**, 그 뒤로 챔버 옆구리의 **환기구 격벽 커버**(회색 가로날개 철문, ADAM 표식)가 드러난다. 가장자리 틈은 사람이 못 들어갈 만큼 좁다.
- 틈을 넓히려고 팀 EVE가 **수도관 밸브를 다시 열어 그 틈으로 물을 흘려보낸다**(확정 2026-11-14). 물이 씨앗에 닿으면 자라는 부작용은 ADAM도 팀 EVE도 몰랐다.
- **전당포 가운데 유리 진열함 3개(초록 받침, 판매용 총이 1정씩 총 3정)에서 총을 꺼내** 물에 들뜬 격벽 커버를 쏘아 부수고 챔버 안으로 들어간다(사건보고서 6번과 일치).

### 4. 챔버 — 반전
- 금고 안에 선악과는 없고 **금고를 뚫고 자란 나무**만 있다. 틈을 넓히려고 흘려보낸 물이 금고 속 씨앗에 닿은 부작용.
- 팀 EVE와 스네이크는 나무를 더 키워 **새 선악과를 열리게** 한다.
- ADAM 비상용 보관 케이스에 담아 하수도로 빠져나온다. 뒤에서 챔버 자폭.

### 5. 하수구 → 흩어짐 → 한 달 뒤 The LUST (확정 2026-11-14)
- 챔버에서 빠져나온 뒤, 선악과를 담은 특수 보관 케이스째 **하수구(바닥 철제 덮개) 아래 물길로 흘려보내 스네이크에게 전달**.
- 미리 준비된 보수·여권·신분증을 챙겨 **한 달 동안 세계 각지로 뿔뿔이 흩어져** 추적을 따돌림.
- 한 달 뒤 스네이크의 연락 「BAR The LUST에서 모이자」 → 돌아왔지만 스네이크는 없고 **편지 한 통**만.
- 편지(매장 소품 원문) = ADAM은 도난 사실을 공표하지 않음·공식 추적 없음 / 태초의 신부는 스네이크가 찾던 물건이 아니었음 / 선악과로 신체 강화 가능 → ADAM과 싸우는 데 도움 / 보답으로 **선악과를 정제한 알약**(먹어도 팔아도 됨) / PS. ADAM과의 싸움에서 더 큰 보상을 원하면 **블랙카드**(FANTASTRICK PREMIUM · Forbidden Fruit · FIRST FOUND BRIDE:EVE PROJECT)를 갖고 있으라, 다시 연락하겠다.

### 6. 에필로그 — 수십 년 뒤 (엔딩 영상)
- 다시 아지트. 할아버지 무릎엔 봉인이 뜯긴 낡은 편지. "그 알약을 먹었냐고, 팔았냐고? 그 까만 카드는? 그 뒤의 일은 다음에 들려주마."
- 이때 처음으로 손자 이름 **'카인'**이 불린다.

### 부록 — ADAM 사건보고서 (쫓는 쪽의 기록)
- 사고명: 선악과의 씨앗 = 코드명 〈태초의 신부〉 도난 사건 / 2017년 1월 / 에덴 거리.
- 사건 과정 7단계(Lust Bar 미팅 → 폭우·낙뢰 → 정전·복구 → 챔버 상승 → 하수시설 폭파·PAWN Shop 보안 해제 → 총으로 환기구 격벽 파손 → 강제 성장·자폭).
- 조치: 통신 기록에서 반복된 이름 'SNAKE'. 유력 용의자 = The LUST Bar 임시 담당자, 행방 묘연.
- 팀 EVE의 정체는 끝내 모른다.

## 설정집에 옮길 때 주의

1. 보고서("챔버 상승 후 씨앗이 급속 생장")와 스토리("금고 안에서 이미 싹이 터 있었다")가 다름 → ADAM이 잘못 파악한 것으로 둔다(쫓는 쪽은 진실을 모른다).
2. 보고서 서명이 실존 인물 이름의 필기체로 보임 → 웹에선 가상의 ADAM 보안책임자 서명으로 교체.
3. 문짝 NE·RO·IX·ZE·SI·ON 글자 등 퍼즐 답이 될 수 있는 것은 설정집에 싣지 않는다(스포일러).
4. 7개 장치의 실제 해제 순서는 방 진행 순서와 맞출 것(아직 미확인).
