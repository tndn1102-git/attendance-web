## 7. 🤖 웹 UI 자동화 — 만들어둔 것 (2026-08-30)

### 파일
| 파일 | 역할 |
|---|---|
| `tools/mureka_login.js` | 최초 1회 Mureka 로그인 → `.pw-profile` 에 세션 저장 |
| `tools/mureka_web.js` | 프롬프트 파일 → 생성 → 완료 대기 → 다운로드 → 매니페스트 |
| `tools/mureka_gen.py --emit-json` | 🆕 파싱만 해서 JSON 으로 넘긴다(과금 0) |

🔑 **파서를 두 벌 만들지 않았다.** `mureka_web.js` 가 `mureka_gen.py --emit-json` 을 불러 쓴다.
왜 = 머리말이 곱으로 잡히는 가드가 한쪽에만 남으면 사고가 난다(가요 EP01 실제 사례).
그래서 기존 4블록 포맷(【LYRICS】/【STYLE】/【EXCLUDE】/【TITLE】)과 1,000자 상한 가드가 그대로 살아 있다.

### 쓰는 법
```
node tools/mureka_login.js                       # 최초 1회 (창이 뜼면 로그인 후 창 닫기)
node tools/mureka_web.js --probe                 # 화면 구조·Gold·모델 확인 (Gold 0)
node tools/mureka_web.js <프롬프트> --out <폴더> --dry-run   # Create 직전까지 (Gold 0)
node tools/mureka_web.js <프롬프트> --out <폴더> --takes 1 --model V7.6
HEADFUL=1 node tools/mureka_web.js ...           # 봇탐지로 막힐 때 폴백
```

### 실측으로 잡은 셀렉터 (2026-08-30)
| 용도 | 셀렉터 |
|---|---|
| 가사 | `textarea[placeholder^="Enter lyrics here"]` (5,000자) |
| 스타일 | `textarea[placeholder^="Enter style, mood"]` (**1,000자**) |
| 제목 | `input[placeholder="Enter song title"]` (50자) |
| Instrumental | `[role=switch]` |
| 생성 | `button:has-text("Create")` |
| 라이브러리 한 줄 | `.search-result-item` |
| 다운로드 | `.audio-item-more-btn-download` |

클래스 대신 **placeholder 로 잡았다** — Mureka 는 8/26 v1.6.2 로 UI 를 바꿨다. 클래스는 재생성되지만 placeholder 문구는 잘 안 바뀐다.

### ⚠️ 실측에서 드러난 함정 — 값을 밀어넣기만 하면 안 들어간다
무료 50 Gold 로 테스트 1건을 돌렸는데, STYLE 을 넣었는데도
라이브러리에 **"Randomly Generate A Song"** 으로 찍혔다 = 스타일이 빈 채 생성됐다는 뜻이다.
React 제어 컴포넌트라 값만 넣으면 화면에만 보이고 상태에는 안 들어간다.
→ `mureka_web.js` 는 Playwright `fill()` 을 쓰고, **넣은 뒤 반드시 되읽어 길이를 대조**한다(`fillChecked`).
안 맞으면 생성하지 않고 멈춘다. **조용히 빈 프롬프트로 생성되는 게 가장 비싼 사고다.**
