# 02 팔도 선택 카드 후보 (korea-regional-travel-curator, 2026-10-18)

8개 방(도)마다 **음식 · 장소/명소 · 체험/축제/전통** 세 묶음, 묶음당 4~5장. 모두 **115장**(도별 14~15장)에 대체 후보는 따로 적었다.
출처는 이번 작업에서 웹검색으로 확인한 한국관광공사(대한민국 구석구석·VISITKOREA), 지자체 관광 포털, 국가유산청, 축제 공식 사이트 URL이다.

## 먼저 읽을 것 (핵심)

1. **기존 DM 48건 중 44건을 카드에 그대로 이었다(★ 표시, 전북은 4건·나머지 5~6건).** 노리개·통계의 "도별 미션" 줄기를 살리면서 선택 카드로 갈아끼울 수 있다.
   남긴 것: 레거시 미니게임으로 바로 이을 수 있는 소재. 뺀 것: 지역성이 약하거나 출처 확인이 안 된 것(아래 "걸러낸 것" 표).
2. **현장 전시물과 겹치는 소재를 일부러 넣었다(◆ 표시).** 사랑채 현장(현장자료_검토.md)에 실제로 걸린 안성 줄타기·양주 별산대·수원 능행차·월미바다열차·영월 장릉·정선아리랑·원주 한지·고창 답성놀이·남해 다랭이·진해 군항제·함안 낙화·제주 돌하르방·영주 무섬·포항 스페이스워크·부여 궁남지. 관람객이 전시장에서 본 것을 폰에서 다시 고르는 구조가 된다.
3. **운영 기간(11/2~12월)과 맞는 제철·행사 ❄ 표시.** 영덕대게·과메기·상주 곶감·제주 감귤 따기·고창 모양성제(작년 10/29~11/2)·광주비엔날레(~11/15)·탐라문화제(10/17~21). "지금 가면 있는 것" 대사에 쓸 수 있다.
4. **행정구역 표기 주의.** 2026년 대한민국 구석구석 주소가 "전남광주통합특별시 보성군"으로 나온다(보성다향대축제 페이지). 기획서의 "전남=광주 포함"과 맞지만, 화면의 방 이름은 현장 안내판(호남권 '울림')을 따르는 게 안전하다.
5. **실제 상호는 0건.** 음식은 모두 "음식 이름 + 지역" 또는 "거리·골목 이름"으로 적었다. 남산서울타워·알펜시아 스키점프대처럼 업체가 운영하는 시설은 랜드마크 이름으로만 쓴다(주의 표시).

### 표 읽는 법
- **외국인**: 상 = 사진 한 장으로 바로 알아봄 / 중 = 한 줄 설명이 있으면 앎 / 하 = 설명이 꼭 필요함
- **컨셉**: 기획서 6개(뷰티·먹방·음식·관광·여행·전통). 먹방 = 먹는 장면, 음식 = 만드는 장면. 카드 하나에 1~2개.
- **연속**: ★ = 기존 DM 미션과 같은 소재, ◆ = 현장 전시물과 같은 소재
- **그림 소재**: 일러스트 한 장에 무엇을 그리면 알아보는가
