# 03. 멀티엔딩 세트 설계 (서사 디자이너, 2026-10-18)

> 결론 먼저: **엔딩 30개** = 큰 갈래 6개(성공이 어디에 닿았나) × 작은 갈래(무엇을 찍었나 / 어느 도에 마음을 뒀나).
> 기존 **21유형은 엔딩 카드 안 "성향 배지"로 남기고**, **노리개는 엔딩마다 모양이 달라지는 마지막 이미지**로 회수한다.
> 엔딩 30 × 배지 21이라 같은 카드가 잘 안 겹친다. 그래서 "나는 뭐 나왔어?" 하고 서로 비교하게 된다.

---

## 0. 왜 엔딩이 여러 개여야 하나 (한 문장)

**한국을 좋아하는 방식은 하나가 아니고, 그 여행에서 무엇이 성공이었는지는 직접 다녀온 관람객만 정할 수 있다.**
엔딩이 "구독자 100만" 하나뿐이면 노포 할머니 레시피를 받아 적은 사람, 해녀 학교 막내가 된 사람, 마을회관 벽에 어르신 사진을 건 사람의 성공은 지워진다. 국민화합 프로그램이 "성공은 하나"라고 말하면 메시지와 어긋난다.

---

## 1. 무엇이 엔딩을 가르나 (변수 4개만)

2주 안에 만들 수 있게 변수는 4개로 줄였다. 컨셉 점수는 기존 통계를 그대로 쓴다.

| 변수 | 어디서 생기나 | 값 | 기존 통계와 관계 |
|---|---|---|---|
| ① **컨셉** (무엇을 찍었나) | DM 수락·별점 (기존 그대로) | 6컨셉 점수 → 1위 컨셉 | 그대로 |
| ② **화제 ↔ 진심** (누구를 위해 찍었나) | 도마다 1장 "태도 카드" (4개 도) | 진심 개수 0~4, "나중에" 개수 | 새 이벤트 |
| ③ **혼자 ↔ 함께** (누구와 찍었나) | 도마다 1장 "태도 카드" (나머지 4개 도) | 함께 개수 0~4 | 새 이벤트 |
| ④ **넓게 ↔ 깊게** (어디에 마음을 뒀나) | 도 끝마다 "하루 더 머물기" + 마지막 "다시 가고 싶은 곳" | 하루 더 횟수 0~8, 고른 도 1개 | 새 이벤트 |
| (숨은) **엽서** | 도마다 작은 우체통 버튼, 보상 표시 없음 | 0~8장 | 새 이벤트 |

### 1-1. 태도 카드 8장 (정답 없는 선택)

각 선택지는 지키는 것과 잃는 것이 다 있다. 화제 쪽도 "속물"이 아니다. 더 많은 사람이 그 동네를 알게 되니까.

| 도 | 축 | 상황 | 선택 A | 선택 B | A가 지키는 것 / 잃는 것 | B가 지키는 것 / 잃는 것 |
|---|---|---|---|---|---|---|
| 전남 | 화제/진심 | 여수 돌게장 영상 썸네일 고르기 | 큰 글씨 "역대급 밥도둑!!" | 사장님 손 클로즈업 "40년 손맛" | 많은 사람이 여수를 안다 / 사장님 이야기 | 사장님이 주인공 / 클릭 수 |
| 서울경기 | 화제/진심 | 광장시장 빈대떡, 손님 줄이 너무 길다 | 줄 맨 앞에서 바로 찍기 (사장님 허락함) | 줄 서서 차례 기다리며 찍기 | 오늘 안에 영상 / 시장의 풍경 | 손님들의 시간 / 촬영 시간 |
| 전북 | 화제/진심 | 판소리 명창 "한 판 다 올려 줘" | 30초 숏폼으로 자르기 | 20분 완창 그대로 올리기 | 판소리를 처음 듣는 10대 / 소리의 흐름 | 예술의 온전함 / 끝까지 볼 사람 수 |
| 경남 | 화제/진심 | 유등축제 하이라이트 | 드론쇼와 섞어 화려하게 | 유등 하나 띄운 할아버지 사연 | 축제의 규모 / 한 사람의 마음 | 한 사람의 사연 / 축제의 크기 |
| 경북 | 혼자/함께 | 하회 나룻배 사공 "손주도 같이 태워도 되나?" | 정중히 혼자 타고 깔끔한 컷 | 손주랑 셋이 타기 (흔들림) | 완성도 / 우연한 웃음 | 사람 / 깔끔한 컷 |
| 충청 | 혼자/함께 | 세종 옥상정원, 견학 온 초등학생들 "저희도 나와요?" | 아이들 없는 시간에 따로 찍기 | 아이들과 같이 드론 날리기 | 풍경 / 아이들의 하루 | 아이들 / 조용한 풍경 |
| 제주 | 혼자/함께 | 감귤 농장에서 만난 외국인 여행자 "같이 다녀도 돼요?" | 내 일정대로 혼자 | 남은 여행 동행 | 내 속도 / 새 친구 | 새 친구 / 내 속도 |
| 강원 | 혼자/함께 | 정동진 해돋이, 옆 가족이 "사진 한 장만" | 해 뜨는 순간 내 촬영 먼저 | 가족 사진 찍어 주다 해 뜨는 순간 놓침 | 완벽한 타임랩스 / 남의 추억 | 그 가족의 사진 / 내 타임랩스 |

- 화제/진심 카드 4장에는 작은 세 번째 버튼 **"나중에 고를게요"** 가 있다 (웃긴 엔딩 '편집 중 87%' 용).
- **하루 더 머물기**: 도 끝마다 "하루 더 / 다음 도로". 하루 더 = 숨은 장소 장면 1개(30초). 대가 = 다음 도의 첫 DM이 "다른 크리에이터가 먼저 찜했어요"로 사라진다(DM 6→5). 뻔한 정답이 안 되게 하는 장치.

### 1-2. 마지막 두 장 (경험의 정점, 여기를 가장 공들인다)

사람은 경험 전체를 가장 강했던 순간과 마지막 순간으로 기억한다(Kahneman 외, 1993, *Psychological Science* 4(6), "When More Pain Is Preferred to Less"). 그래서 엔딩을 가르는 마지막 결정은 숨은 점수에 맡기지 않고 **관람객이 직접 고르게** 한다.

**카드 A, 돌아가는 기차 창가.** "마지막 영상 한 편만 더 올릴 수 있다면?"

| 고르는 것 | 더해지는 값 |
|---|---|
| 구독자에게 보내는 고마움 하이라이트 | 화제 +1 · 혼자 +1 |
| 다 같이 웃던 장면 모음 (축제·장터) | 화제 +1 · 함께 +1 |
| 아무도 몰랐던 장면 한 컷 | 진심 +1 · 혼자 +1 |
| 만난 사람들 얼굴 모음 | 진심 +1 · 함께 +1 |

**카드 B, 창밖으로 8도 띠돈이 하나씩 지나간다.** "다시 가고 싶은 곳 하나만." (8도 중 택1)

## 2. 갈래 구조 (대분류 6 × 소분류)

```
판정 순서:  ① 숨은 엔딩 확인 → ② 아쉬운·웃긴 엔딩 확인 → ③ 뿌리 엔딩 확인 → ④ 사분면(화제/진심 × 혼자/함께) → ⑤ 1위 컨셉으로 소분류
```

| 대분류 | 들어가는 조건 | 성공이 닿는 곳 | 엔딩 수 | 노리개의 마지막 모습 |
|---|---|---|---|---|
| **A. 큰 무대** | 화제 > 진심, 혼자 ≥ 함께 | 세계·전국 (숫자·해외·공식 채택) | 4 | 삼작노리개가 골드버튼·무대 조명에 반짝임 |
| **B. 축제판** | 화제 > 진심, 함께 > 혼자 | 여럿이 모인 현장 (라이브·축제·공동채널) | 3 | 삼작 중 하나를 함께한 사람의 가방에 달아 줌 (이작이 됨) |
| **C. 기록** | 진심 ≥ 화제, 혼자 ≥ 함께 | 오래 남는 것 (영화제·책·지도·박물관) | 4 | 노리개가 유리장·책 표지·크레딧 마지막 컷에 놓임 |
| **D. 사랑방** | 진심 ≥ 화제, 함께 > 혼자 | 가까운 사람들 (마을·가게·교실) | 4 | 노리개를 어르신·아이가 손에 쥐고 흔듦 |
| **E. 뿌리 (8도)** | 카드 B에서 고른 도에서 **하루 더** 머물렀고, 하루 더 총 2회 이하 | 그 한 곳 | 8 | 삼작 대신 **그 도 띠돈만 크게** 걸린 단작 |
| **F. 아쉬운·웃긴** | 특수 조건 | 아직 덜 닿았거나 엉뚱한 곳 | 4 | 고리 빈자리가 남은 미완성 노리개 |
| **G. 숨은** | 특수 조건 | 예상 못 한 곳 | 3 | 특별한 노리개 (팔도 띠돈 / 여섯 장식 / 엽서에 그린 노리개) |
| | | | **30** | |

**사분면 동점 처리**: 화제 = 진심이면 진심 쪽, 혼자 = 함께면 함께 쪽 (마지막 카드 A가 이미 더해진 뒤라 동점은 드물다).
**방문한 도가 8개 미만이면** 비율로 판정 (예: 태도 카드 3장 중 2장).

## 3. 엔딩 30개

칭호는 "○○ 크리에이터"를 붙이지 않고 짧게 쓴다(배지가 이미 "○○ 크리에이터"라 겹침). 마지막 장면의 **채널 이름**은 입구에서 고른 이름이 들어간다. 30개 엔딩 모두 이 이름으로 끝난다(입구에서 심은 복선을 결말마다 다른 물건으로 회수).

## 7. 도감 (오른쪽 위 상시 버튼)

데트로이트 비컴 휴먼은 챕터가 끝나면 지나온 길과 못 간 길(회색)을 순서도로 보여 주고 완료율을 표시한다. 같은 방식으로 "못 본 엔딩이 있다"를 보여 줘서 다시 하고 싶게 만든다.

| 항목 | 내용 |
|---|---|
| 배치 | 갈래 7줄(A~G), 줄마다 엔딩 칸. E줄은 8도 지도 모양으로 배치 |
| 본 엔딩 | 그림 + 칭호 + 처음 본 날짜 |
| 못 본 엔딩 (A~E) | 회색 실루엣 + 칭호 + **힌트 한 줄** (예: "제주에서 하루 더 머물고, 다시 가고 싶은 곳으로 제주를 고르면…") |
| 못 본 엔딩 (F) | 실루엣 + "???" + 웃긴 힌트 (예: "녹화 버튼… 눌렀죠?") |
| 못 본 엔딩 (G) | 자물쇠 + "숨은 엔딩" 만, 힌트 없음. 1개라도 찾으면 나머지 G에 흐린 힌트 생김 |
| 상단 | "30개 중 ○개" 진행 막대 + 모은 성향 배지 수 (21개 중) |
| 저장 | localStorage (네트워크 없음) |

**현장 확인 필요**: 관람객이 **자기 폰**으로 하면 위 그대로 된다. **사랑채 공용 태블릿**이면 도감이 다음 관람객에게 넘어가 버린다. 공용 기기면 "처음부터" 버튼으로 도감을 지우거나, 개인 도감 대신 "오늘 이 기기에서 나온 엔딩" 집단 도감으로 바꾼다(남이 찾은 엔딩을 보는 것도 국민화합 톤에 맞음).

| 엔딩 장면 그림 | 30장 | 같은 배경 틀 + 소품만 바꿔 그림. E 8장은 기존 3D 방 장면 정지 컷 재활용 |

| 태도 카드 | 8장 + 마지막 2장 | 물회식 카드 한 장 = 사진 1 + 버튼 2~3 |
| 하루 더 숨은 장면 | 8개 | 사진 1장 + 문장 2줄로 충분 (미니게임 아님) |
| 텍스트 | 30 엔딩 × 5개 언어 | 칭호·한 줄·예고 3줄만. 장면 설명은 그림이 대신 |

**먼저 만들 것 (시안용)**: A1, C1, D4, E5, F1, G3 여섯 개. 갈래가 서로 다르게 보이는지는 이 6장으로 판단할 수 있다.

## 10. 원청에 확인할 것

1. 실제 기관·장소 이름(인천공항 입국장, 전주국제영화제, 고인쇄박물관, 해녀 학교 등)을 엔딩 그림에 써도 되나. 안 되면 "공항", "영화제"로 일반화.
2. F 갈래(아쉬운·웃긴)를 넣어도 되나. 넣는다면 F3 "숫자는 커졌는데"의 톤 확인.
3. 공용 기기인지 개인 폰인지 (도감 저장 방식).
