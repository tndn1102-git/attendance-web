## 참고 사이트 분석: 「물회의 취향」 (mulhoe.vercel.app, 실측 2026-10-18)
- Next.js, 폭 480px 고정 세로 카드. 배경 무지개 그라디언트, 글꼴 Gothic A1 + Dongle.
- 흐름: **포스터 시작 화면**(일러스트 포스터 1장 + "테스트 시작하기") → **질문 10개가 한 페이지에 세로로 이어짐**(카드 한 장 = 질문 1개) → "결과 보기" → **"분석 중..." 스피너** → **결과: 맞춤 맛집 1위·2위 카드**(사진·이름·주소·전화) → 다시 하기. 오른쪽 위 상시 **"물회 도감"** 버튼(전체 결과 모음).
- 질문 형식 4종: 택1 텍스트 버튼 / **사진 카드 다중선택**(해산물 9·고명 18) / 사진 카드 택1(그릇 4) / **0~5 슬라이더**(염도·당도, 양끝에 말 라벨).
- 결과 후보 = 속초 물회집 25곳. 선택이 가게 속성과 얼마나 맞는지 점수로 1·2위.
- 강점: 사진 카드 고르는 맛, 3분 안에 끝남, 결과가 "나한테 맞는 실제 무언가", 도감으로 수집욕.
- 약점: 이야기 없음, 결과가 2개만 보임, 질문이 서로 독립(앞 선택이 뒤에 영향 없음).
