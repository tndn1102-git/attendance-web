K의 나라 개편 시안

팔도 여행 → 성공한 K-크리에이터 · 멀티엔딩 36개 · 2026-10-18 · 오른쪽 폰 화면은 실제로 눌러 볼 수 있음

1참고 사이트에서 가져오는 것

물회의 취향 (mulhoe.vercel.app)

  • 포스터 시작 화면 → 질문 카드 10장이 세로로 이어짐
  • 형식 4종: 택1 · 사진 카드 다중선택 · 사진 카드 택1 · 0~5 슬라이더
  • "분석 중..." → 맞춤 결과(맛집 1·2위) → 다시 하기
  • 오른쪽 위 상시 "도감" (결과 25개 모음)
  • 약점: 이야기 없음, 결과 2개만, 앞 선택이 뒤에 영향 없음

K의 나라 새 구조

  • 도 안에서는 물회처럼 카드 4장 세로, 탭 한 번에 다음 카드
  • 도와 도 사이는 지도에서 자유 이동 (여행 느낌)
  • 도마다 미니게임 1개 = "촬영" (실력 측정, 원청 요구)
  • 구독자가 쌓이고, 매니저 '다온'·'첫댓요정'이 말을 건다
  • 결과 = 엔딩 36개 중 하나 + 도감

2관람 흐름 (8도 완주 약 9분, 엔딩 약 1분 30초)

포스터→채널 이름→꿈 고르기→지도→ 도 ×8 (순서 자유)→분석 중→엔딩 장면·결과 카드→도감·다시하기

도 하나 (약 55초)

① 어디부터 갈까 (장소·사진 택1)→② 뭐 먹지 (택1 또는 다중)→③ 오늘 메인 영상 (택1 = 미니게임)→④ 어떻게 찍지 (슬라이더 또는 5지선다)→도별 미니게임 5~12초→업로드 반응·노리개

4도부터 지도에 "여기서 결산" 버튼. 2도 이하에서 끝내면 '1화 업로드 완료' 엔딩.

컨셉 6 (뷰티·먹방·음식·관광·여행·전통)①②③ 카드1위 컨셉 = 엔딩의 "무대"
촬영 스타일 (연출 – 날것)④두 축으로 사분면: 방송국형 · 다큐형 · 라이브형 · 브이로그형

실력 ★0~3촬영 미니게임구독자 → '골드버튼' 숨은 엔딩

판정 순서: 1화(2도 이하) → 언플러그드 → 지역 몰입 → 골드버튼 → 팔도 만능 → 정규 24. 무작위 응답 10만 회 시뮬: 정규 엔딩 각 3.0~4.4%, 숨은 엔딩 각 0.7~2.7%, 안 나오는 엔딩 0개.

4엔딩 36개

정규 24 = 1위 컨셉 × 사분면

지역 몰입 8 · 특수 4

엔딩마다 "성공의 모양"이 다름: 해외 연사, 박물관 상설 영상, 노포가 다시 문 엶, 교실 수업 자료, 공항 홍보 영상, 축제 사회자 등. 결과 카드에는 21유형 배지·삼작노리개·추천 지역이 함께 붙음.

6엔딩 6장면 — 실제 방문까지 잇기

마지막 업로드 (꾹 누르기)→① 엔딩 장면·칭호→② 1년 뒤 이야기→③ 나랑 잘 맞은 팔도 순위→④ 실제로 가 보기 1박 2일→⑤ 채널 결산→⑥ 첫댓요정 반전·도감
  • ③ 잘 맞은 팔도: 다녀온 도마다 궁합 % = 고른 카드가 내 1·2위 컨셉과 맞는 정도 + 촬영 별점 + 현지인 추천 따른 정도. 1~3위는 그 도에서 고른 것과 "가장 나다웠던 것 ★"을 보여 줌
  • ④ 실제로 가 보기: 1위 도의 1박 2일 코스. 고른 것(내가 게임에서 고른 장소·음식·체험)에 새로 발견(같은 도에서 내 취향과 맞는 곳)을 섞음. 항목마다 시군·한 줄·공식 관광 안내 링크(대한민국 구석구석·지자체·국가유산청, 큐레이터가 확인한 115곳), 11~12월 제철·행사 표시, 2·3위 도와 안 가 본 도 추천
  • 본 작업: 코스를 이미지 저장 + QR로 폰에 가져가게 → 전시장 밖 실제 방문으로

8정해 주셔야 할 것

  1. 코스를 가져가는 방법: 이미지 저장 / QR로 폰에 결과 페이지 / 현장 출력 중 무엇 — 그리고 게임 안에서 공식 관광 사이트 링크를 열어도 되는지(원청)
  2. 결산 가능 최소 도: 4도(시안) vs 3도 · 노리개 굿즈는 몇 도부터 주는지
  3. 엔딩에 실존 기관명(공항·영화제·박물관·성산일출봉 등) 써도 되는지 — 원청 확인
  4. 개인 폰인지 사랑채 공용 태블릿인지 (공용이면 도감을 관람객마다 비워야 함)
  5. 카드 그림: 지금은 이모지 자리표시. 일러스트(물회처럼 손그림) vs 사진 vs 기존 3D
  6. 새 문구 약 250개 × 5개 언어 — 납기(11-01) 전 번역 범위
