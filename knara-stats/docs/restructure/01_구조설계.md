# 01. 게임 뼈대 · 엔딩 판정 시스템 (선택형 테스트 설계, 2026-10-18)

> 범위: 8도 장면 구조 · 질문 형식 · 측정 축 · 누적 상태 · 엔딩 개수·판정 규칙 · 분포 시뮬레이션 · 미니게임 입장 · 소요 시간 · 도감/공유/다시하기 · 통계 이벤트.
> 판정 로직 참조 구현 = 같은 폴더 `sim.mjs` (`node sim.mjs` → 10만 회 × 4모델, 약 8초).
> 엔딩 문구·장면은 03, 장면 연출은 04, 도별 카드 실물은 02가 맡는다. 이 문서는 **그 내용이 꽂힐 틀과 판정 규칙**이다.

## 2. 화면 흐름과 도 하나의 틀

```
[포스터 시작] → [채널 이름 3택1] → [지도: 도 고르기] ─┐
   ┌─────────────────────────────────────────────┘
   └▶ [도 화면: 질문 카드 4장 세로] → [촬영 미니게임 20~25초] → [업로드: 구독자↑·노리개 장식] → 지도 (×8, 순서 자유)
        → [분석 중… 3초] → [엔딩 장면] → [결과 카드: 근거 3컷·축 막대·21유형 배지·삼작노리개·추천 지역] → 도감/저장/다시하기
```

- **도 순서는 자유**(전시장 동선과 맞춤, 04와 같은 입장). 판정은 순서와 무관하게 설계했고, 시뮬도 방문 순서를 무작위로 섞어 검증했다.
- **4도부터 "여기서 결산"** 버튼이 지도에 뜬다. 2도 이하에서 끝내면 특수 엔딩 '1화 업로드 완료'.
- 강원(11/11 전)은 지도에 "11/11 공개" 자물쇠. 7도만 돌아도 판정이 정상 동작(모델 다).

### 2-1. 장면 4개 (도마다 같음, 형식만 돌아감)

| 장면 | 화면 질문 (예) | 형식 | 선택지 유형 | 주는 점수 |
|---|---|---|---|---|
| **S1 도착** | "전남 도착! 어디부터 갈까?" | 사진 카드 **택1** (4장) | 장소·체험 | 컨셉 +2(2차 +1) · 페이스 ±1 · 현지인 카드면 몰입 +1 |
| **S2 뭐 먹지** | "점심은?" / "골라 담아요(최대 3)" | 사진 카드 **택1** 또는 **다중 1~3** (4장) | 음식 | 컨셉 합 +2(다중이면 나눠 가짐) · 다중 개수 → 페이스(1개 −1 / 3개 +1) · 몰입 |
| **S3 오늘 찍을 장면** | "오늘 메인 영상은?" | 사진 카드 **택1** (4장) | 촬영 대상 = 미니게임 | 컨셉 +2(2차 +1) · 몰입 · ★→실력·구독자 |
| **S4 어떻게 찍지** | "편집 꽉꽉 ↔ 원테이크 날것" / "어떻게 찍을까?" | **슬라이더 0~4** 또는 **텍스트 택1(5개)** | 촬영 방식·태도 | 스타일 ±2 · (텍스트는) 페이스 ±1 |

S4 텍스트 5개 (style, pace): 시네마틱(−2, −1) · 숏폼 편집(−1, +1) · 라이브(+2, +1) · 브이로그(+1, −1) · *작은 글씨* "오늘은 안 찍고 그냥 즐길래요"(0, 0, 몰입 +1, **촬영 생략**). 네 개가 사분면을 하나씩 맡아 합이 0이다.

## 4. 카드 배치 규칙 (02 팔도카드 작성자에게 넘기는 제약)

### 4-1. 규칙

1. 장면마다 카드 **4장**. 도마다 12장.
2. 1차 컨셉은 도마다 **각 2번**, **서로 다른 두 장면**에 1번씩(같은 장면에 같은 컨셉 2장 금지).
3. 2차 컨셉(점수 절반)은 도마다 **각 1번**.
4. **모든 장면 가중치 같음**(+2). 다중선택은 고른 개수로 나눠서 합 +2(개수는 페이스로만 반영).
5. 장면마다 "현지인 추천" 카드 **1장**, 위치(어느 컨셉 카드인지)는 도마다 바꾼다.
6. S1 장소 카드의 페이스 태그(찍고 다음 +1 / 눌러앉기 −1)는 2장씩, 도마다 뒤집는다.
7. 화면에서 카드 순서는 매번 섞고, 섞인 순서를 통계에 남긴다(위치 편향 확인).

### 4-2. 레이아웃 3종 (S3에 빠지는 컨셉 짝을 돌림)

| 레이아웃 | S1 장소 | S2 음식 | S3 촬영 대상 (= 미니게임) |
|---|---|---|---|
| A (전남·서울경기·강원) | 여행·뷰티·전통·관광 | 뷰티·전통·먹방·음식 | 먹방·음식·관광·여행 |
| B (경북·제주·경남) | 관광·여행·뷰티·전통 | 관광·여행·먹방·음식 | 뷰티·전통·먹방·음식 |
| C (충청·전북) | 먹방·음식·관광·여행 | 먹방·음식·뷰티·전통 | 관광·여행·뷰티·전통 |

음식 장면에 뷰티·전통·관광·여행 카드가 들어가는 건 "음식을 그 컨셉의 눈으로 고르는" 카드다: 뷰티 = 녹차·약선 같은 몸에 좋은 한 상, 전통 = 잔치·향토 음식, 관광 = 야시장·명물 골목, 여행 = 바닷가 도시락·기차 간식.

**예시 — 전남 (레이아웃 A, S2 다중, S4 텍스트)**

| 장면 | 카드 (1차/2차 · 태그) |
|---|---|
| S1 | 담양 죽녹원 대숲 걷기 (여행/관광 · 꽉) · 보성 찻잎 화장품 공방 (뷰티/전통 · 느긋 · **현지인**) · 해남 강강술래 마당 (전통 · 꽉) · 여수 밤바다 산책 (관광 · 느긋) |
| S2 | 보성 녹차 한 상 (뷰티/먹방) · 담양 대통밥 (전통/음식) · 여수 돌게장 백반 (먹방 · **현지인**) · 광주 떡갈비 직접 굽기 (음식) |
| S3 | 돌게장 한 숟갈 리액션 (먹방) ✚ · 녹차 덖기 (음식/뷰티) ✔ · 광주·여수·담양 트랜지션 숏폼 (관광/여행) ✔ · 무등산 오르기 (여행 · **현지인**: 산악회 어르신 길) ✔ |
| S4 | 시네마틱 / 숏폼 편집 / 라이브 / 브이로그 / 오늘은 안 찍고 즐기기 |

(✔ 레거시 놀이 그대로, ✚ 새로 — 기획 v0.2 표 기준)

### 4-3. 왜 이 규칙인가 — 시뮬로 확인한 실패 두 가지

| 배치 | 무작위 응답 시 1위 컨셉 분포 | 원인 |
|---|---|---|
| 1차 시안(음식 장면에 먹방·음식만 4장, 촬영 장면 가중 3) | 먹방 4.8% · 음식 2.0% / 나머지 21~26% | 먹방·음식이 한 장면에 몰려 분산이 작고, 무거운 S3에 없음 |
| **04안 그대로**(먹을 것 2장 + 갈 곳 4장, 메인 2택1) | **먹방 42.4% · 음식 41.9%** / 나머지 각 4% | 2장 중 1장(50%)과 4장 중 1장(25%)의 노출 확률 차이 |
| **이 문서 규칙** | 각 16.1~17.5% | 규칙 1~4 |

→ 04의 "먹을 것 → 갈 곳 → 메인" 흐름은 살리되 **장면마다 4장**, **컨셉이 서로 다른 장면에 흩어지게** 바꿔야 한다. 04 작성자와 맞출 것.

## 5. 누적 상태: 구독자

| 넣나 | 무엇 | 이유 |
|---|---|---|
| **넣는다** | **구독자** (화면 위 카운터, 도 끝 업로드 때 오름) | ① 8도 동안 "커지고 있다"는 진행감 ② 엔딩 카드에 "구독자 n명"으로 성공의 크기 ③ 앞 선택이 뒤에 영향을 주는 유일한 수치 장치 |
| 넣지 않는다 | 체력·예산·평판 게이지 | 바닥나면 막히는 자원은 정답(아껴 쓰기)을 만들고, 관리 화면이 늘어 8~12분에 안 맞음. 실패해서 못 가는 도가 생기면 지역 균형(청와대 사업 핵심)이 깨짐 |

구독자 공식 (도마다):
`증가 = (300 + 900×★) × (이번 촬영 컨셉 == 지금까지 1위 컨셉 ? 1.6 : 1.0) × (1 + 0.15×방문 순번)`
- "알고리즘이 채널 색깔을 알아봤어요" — 한 컨셉을 밀면 더 크게 오른다. **엔딩 종류(컨셉·사분면)에는 안 쓰고**, 레전드 판정과 결과 카드 숫자에만 쓴다 → 쏠림 유도가 컨셉 분포를 흔들지 않는다.
- "안 찍고 즐기기" 도는 구독자 0, 대신 몰입 +1.
- 수치 장치 말고 **문구 연결**(04의 재등장 인물·첫댓요정)은 판정과 무관하게 얹으면 된다.

### 6-2. 03안(30개)과의 관계

판정기 구조는 03과 같다: **[특수 확인] → [지역 확인] → [양극 축 2개 → 사분면] → [1위 컨셉 → 소분류]**. 다른 점은 축의 내용과 재는 법뿐이라, 최종 축은 둘 중 무엇을 써도 `judge()`의 `style/pace` 자리만 바꾸면 된다. 다만 03안 그대로면 **분포가 기운다**:

|---|---|---|
| 화제/진심 카드 4장, 혼자/함께 카드 4장, 동점은 "진심 ≥ 화제"·"혼자 ≥ 함께" | A 큰 무대 21.6% · **B 축제판 9.8%** · **C 기록 47.4%** · D 사랑방 21.3% | 이진 카드 4장은 2:2 동점이 37.5%, 그 동점을 전부 한쪽에 몰아줌 |

**권고**: 03의 축(화제/진심·혼자/함께)을 쓰려면 ① 8도 모두에서 재고(도마다 S4를 03의 태도 카드 4지선다로: 화제·혼자 / 화제·함께 / 진심·혼자 / 진심·함께 — 한 번에 두 축을 다 잰다), ② 강도 차(±1/±2)나 다른 장면 태그를 섞어 동점을 줄이고, ③ 동점은 "마지막으로 기운 쪽"으로 깬다. 이 문서의 S4 텍스트 5지선다가 바로 그 모양이다. 소분류를 1위 컨셉 6칸보다 적게(03은 대분류당 3~4개) 묶을 때는 **한 엔딩에 1위 컨셉 2칸까지만** 합쳐야 최대/평균 2.5배 안에 든다.

### 6-3. 판정 규칙 (JS 의사코드 — 실제 코드는 `sim.mjs`의 `judge()`)

```js
function judge(answers, visited) {
  // 1) 누적
  for (도 of visited) {
    add(S1카드, 2); pace += S1카드.pace;
    for (c of S2고른것) add(c, 2 / S2고른개수);  if (다중도) pace += {1:-1, 2:0, 3:+1}[개수];
    add(S3카드, 2);
    if (텍스트도) { style += 옵션.style; pace += 옵션.pace; if (안찍기) { unplug++; local++; } }
    else style += 슬라이더 - 2;                       // 0..4 → -2..+2
    if (!안찍기) { skill[S3.c] += ★; subs += (300+900★)×(S3.c==현재1위?1.6:1)×(1+0.15×순번); }
    depth[도] = 그 도 현지인 카드 수;  full[도] = S1·S2·S3 모두 현지인 (S2 다중은 ≤2개);
  }
  for (c of 6컨셉) if (찍은적있음) score[c] += 0.6 × 평균★[c];   // 실력은 '평균'으로 (기회 수 차이 무력화)
  top  = argmax(score)          // 동점 → 실력 합 큰 쪽
  quad = (style<0?'연출':'날것') + (pace>0?'꽉':'느긋')   // 0이면 마지막으로 기운 쪽, 그것도 없으면 날것/꽉

  // 2) 우선순위
  if (nDo <= 2)                                   return '1화 업로드 완료';
  if (텍스트도방문 >= 3 && unplug >= 3)            return '언플러그드';
  if (full인 도 있음 && local합 >= 10×nDo/8)        return '지역:' + (full 중 depth 최대, 동점은 나중에 간 도);
  if (nDo >= 6 && subs >= 41000×nDo/8)            return '레전드';
  if (nDo >= 6 && (max-min)/max <= 0.30)           return '팔도 만능';
  return top + '-' + quad;                         // 정규 24
}
```

문턱 3개(41,000 / 0.30 / 10)는 시뮬로 맞춘 값. 현장 2~3일 실측 엔딩 분포를 보고 `LEGEND_SUBS=… ALLROUND=… LOCAL_MIN=… node sim.mjs`로 다시 맞춘다.
