## 2. 전체 구조와 감정 곡선

### 2-1. 곡선은 "방문 순번"에 건다 [제안]
순서를 자유로 두면 지역별로 곡선을 짤 수 없다. 그래서 **도 고유 내용(음식·장소·사건)** 위에 **순번 장면**을 덧씌운다.

```
감정  ▲                                                          ★엔딩(정점)
      │                                              ●마지막 직전 훅
      │                       ●5번째: 재회
      │   ●1번째: 첫 업로드
      │ ●오프닝                                ●
      │            ●2번째          ●4번째        6·7번째: 매니저 배신 컷(웃음 정점)
      │                 ▼3번째: 조회수 조용(바닥)
      └──────────────────────────────────────────────────────▶ 방문 순번
```

| 순번 | 덧씌우는 장면 | 감정 | 규칙 |
|---|---|---|---|
| 오프닝 | 채널 개설, 구독자 0 → 1 (복선 ①) | 설렘 | |
| 1번째 도 | 다온이 한 줄씩 더 안내(튜토리얼). 첫 업로드에 하트가 크게 터짐 | 작은 정점 | |
| 2번째 도 | 러닝 개그 반복 시작 | 가벼움 | |
| **3번째 도** | **업로드 후 조회수가 조용함** → 선택(태도 측정) → 첫댓요정 한 줄(복선 ②) | **바닥** | 무거운 장면 뒤 웃음 한 줄 |
| 4번째 도 | 평소 틀 | 회복 | 쉬어 가는 도 |
| 5번째 도 | **앞 도의 사건에서 만난 사람이 댓글로 재등장** (연결 ①) | 따뜻함 | |
| 6번째 또는 7번째 도 | **매니저 먹방 배신 컷** (러닝 개그 배신) | 웃음 정점 | |
| 마지막 도 직전 | "다음 영상이면 1만 명" 훅 | 긴장 | **훅 뒤 개그 금지** |
| 엔딩 | 축하 무대 → 첫 구독자 반전(복선 ③ 회수) → 유형·노리개 → 꿈 회수 | 정점 | 반전 뒤 웃음 한 줄 |

- 3도만 돌고 끝내는 사람: 1번째(정점) → 2번째 → 3번째(바닥)에서 끝나면 안 되므로, **3번째가 마지막이면 바닥 장면을 빼고 바로 훅으로** 넘긴다. 바닥 장면은 "4도 이상 돌 사람"에게만.
- 정확한 규칙: `바닥 장면 = 순번 3 AND 방문 예정이 남아 있음(종료 안 누름)`. 종료 버튼은 도 끝날 때 지도에서 누르므로, 3번째 도 **업로드 장면에서는** 아직 모름 → **바닥 장면을 3번째 도 '다음 도 도착' 화면으로 미룬다**(즉 4번째 도 S1 앞). 4번째에 안 가면 자연히 안 나옴.

### 2-3. 엔딩 대본 뼈대 (7화면) [제안]

엔딩이 낭독회가 되기 쉬운 자리. **화면마다 조작 1번**을 박는다.

| 화면 | 글 | 조작 | 갈리는 것 |
|---|---|---|---|
| E1 | 다온: 마지막 업로드예요. 꾹 눌러 주세요. | **업로드 버튼 길게 누르기** → 구독자 카운터 굴러감 | 누적 구독자 |
| E2 | (무대) 라이브: 축하 라이브, 지금 {n}명이 보고 있어요. / 몽타주: 그동안 찍은 장면을 한 번에 이어 봤어요. / 상영회: 동네 극장에서 내 영상을 틀어 준대요. | [시작] | **촬영 방식 다수결**(연결 ③) |
| E3 | 댓글: "{도} 골목 소리꾼입니다. 그날 들어 줘서 고마워요." 식 — 사건에서 만난 사람 1~2명 | 하트 탭(누른 만큼 하트 날림) | 사건 선택(연결 ①) |
| E4 | 다온 폰 화면이 슬쩍 보임 — 로그인 계정 **'첫댓요정'** / 다온: …1등은 늘 제가 했어요. | [알고 있었어] / [진짜요?] | (가벼운 리액션 선택, 기록만) |
| E4' | 다온: 구독 취소는 안 할게요. 아마도. | 탭 | 반전 뒤 웃음 한 줄 |
| E5 | 유형 발표 + 삼작노리개 꿰기 (기존 결산 화면) | 장식 하나씩 탭해서 꿰기 | 컨셉 21유형 |
| E6 | 꿈 회수 한 줄 (O4 표) | 탭 | 오프닝 꿈 |
| E7 | 다음에 가 보고 싶은 지역을 골라 주세요 (기존 `wish` 문구 재사용) | 지도 택1 → 결과 카드 | 방문 안 한 도가 많으면 "시즌 2 예고" 문구 |

- 엔딩 개수 쪽 서사 제안(정식 판정 규칙은 엔딩 담당 문서와 맞출 것): **무대 3종(라이브·몽타주·상영회) x 꿈 4종 x 유형 21종** + 특수 무대 4종(팔도 완주 / 시즌 1 예고편 / 매니저가 스타가 됨 / 한 도 몰입 "여기 살래요"). 같은 유형이라도 무대와 마지막 한 줄이 달라 "엔딩이 많다"는 체감이 남.

### 3-1. 카드 6장 = 컨셉 6개
- S2 먹을 것 2장: **먹방 1 · 음식 1** ("먹는 쪽이냐, 만드는 쪽이냐")
- S3 갈 곳 4장: **뷰티 1 · 관광 1 · 여행 1 · 전통 1**
- 지금 DM 편의 "도마다 컨셉 6개 의뢰"와 1:1로 맞물려, 통계 사이트의 컨셉별 관심 기록을 그대로 이어 쓸 수 있음.
- 관심 점수(안): S2·S3에서 고름 +2, S4 메인으로 고름 +2 추가, 고르지 않은 카드 0 (지금 판의 "다음에 −1"은 **카드 6장 중 5장이 자동으로 거절**되는 구조라 빼는 게 맞음 — 점수 담당과 맞출 것).

### 3-2. "설문처럼 안 느껴지게" 하는 장치 — 어디에 무엇을

| 구독자 카운터 | 화면 위 상시, S8에서 굴러감 | 누적이 보임 = 연재감 |

| 순번 장면 | 3번째 바닥, 5번째 재회, 6~7번째 배신 컷 | 8번 같은 틀이 반복되어도 이야기가 앞으로 감 |

### 3-3. 반응은 **정답 없는 반응** [중요]
고를 때마다 하트 수가 다르면 플레이어는 정답 찾기를 시작하고, 측정이 오염된다. 그래서
- 선택마다 **하트 수는 같고, 반응하는 시청자가 다르다**(먹방 고르면 먹방 시청자, 전통 고르면 전통 시청자).
- 구독자 증가 폭은 **별(실력)만** 좌우한다 (기존 `SUBS = [40, 260, 720, 1400]` 그대로).
- 악플은 쓰지 않는다. 바닥 장면도 "조용함"이지 "비난"이 아니다.
