노리개 구조는 실제와 같이 **띠돈 → 매듭 → 주체 → 술** 4단. 띠돈에는 방(도) 문양, 술 색은 실력 단계.

## 3. 관람 흐름

1. **채널 개설** (입구): 직업 고르기 대신 채널 이름 짓기(자동 추천 + 바꾸기). 빈 노리개 띠가 화면에 걸린다.
2. **도 미션판**: 방에 들어오면 카드 6장 = 컨셉 6개가 하나씩. 관람객이 하나 고름 → 놀이 → 다시 판으로, 3번.
   - 1순위 고른 컨셉 +3, 2순위 +2, 3순위 +1 (관심 점수)
   - 안 고른 3장도 기록 (관심 없음 신호)
3. **업로드**: 판이 끝날 때마다 성과를 조회수로 보여 줌 (★0~3 → 조회수 구간). 실패해도 0이 아니라 '조회수 적음'. 목숨 없음 유지.
4. **도 노리개 받기**: 방 3판이 끝나면 그 방에서 **관심+실력 합이 가장 높은 컨셉**의 주체 1개를 받는다. 띠돈은 그 도 문양.
   - 방을 다 못 돌아도 방마다 하나씩 쌓이므로 전시 동선에 강하다.
5. **최종 삼작노리개** (출구): 모은 주체 중 전체 점수 상위 3 컨셉으로 **삼작노리개** 완성.
   - 칭호: "○○ 채널 — 먹방·전통 크리에이터"
   - 채널 리포트: 컨셉별 비율(관심/실력 두 줄), 총 조회수, 대표 장면 3컷

점수식(안): `컨셉 점수 = 관심(1순위3·2순위2·3순위1) + 실력(★0~3) × 1.5`
→ 좋아서 고른 것과 잘한 것이 비슷한 무게. 숫자는 플레이테스트 후 조정.
