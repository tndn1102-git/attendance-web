# K의 나라 — DM 편 기획서 (v0.2, 2026-10-11)

방향: **DM(관심) + 성향 유형(결과)**. 이전 초안은 `기획-v0.1.md`, 방향 후보는 `방향.md`.

---

## 1. 한 줄

관람객은 막 채널을 연 **K-크리에이터**. 전국 8개 도를 돌며 지역 의뢰인의 **DM**을 골라 받고, 촬영(미션)을 해낸다.
의뢰인은 고마움의 표시로 **노리개 장식**을 보내고, 출구에서 내가 어떤 크리에이터인지 **유형**과 **삼작노리개**가 완성된다.

## 2. 원청 요구 대응

| 원청 요구 | 이 기획에서 |
|---|---|
| 직업 = 한국 관련 크리에이터 하나 | 직업 선택 삭제. 입구에서 채널 이름만 정함 |
| 도별 미션 진행 | 방마다 의뢰 3건 촬영 (기존 한 방 3판 유지) |
| 어떤 미션에 관심이 있었나 | DM을 **수락/다음에**로 넘김. 수락·거절 둘 다 기록 |
| 어떤 미션을 잘했나 | 촬영마다 의뢰인 별점 ★0~3 |
| 뷰티·먹방·관광·여행·음식·전통 노리개 | 컨셉 6개 = 노리개 장식 6종. 방마다 1개, 출구에서 삼작 |

## 3. 관람 흐름

```
[입구] 채널 개설 ─▶ [방 1~8] DM함 ⇄ 촬영 ⇄ 리뷰 (×3) ─▶ 노리개 선물 ─▶ [출구] 채널 결산 · 유형 · 삼작노리개
```

### 3-1. 입구 — 채널 개설
- 채널 이름 자동 추천 3개(예: "팔도 한입", "K길 위에서", "오늘도 로컬") 중 고르거나 다시 뽑기. 타자 입력 없음.
- 구독자 0명, 빈 노리개 띠돈이 화면 위에 걸린다.
- 레거시의 '직업 고르기' 자리에 들어간다.

### 3-2. 방 — DM함
- 방에 들어오면 폰에 알림처럼 DM이 **한 통씩** 뜬다. 그 도의 의뢰 6건(컨셉 6개)이 무작위 순서로.
- DM 한 통 = 의뢰인 프로필 + 사진 1장(그 미션 장면 미리보기) + **한 줄 부탁**.
- 버튼 두 개: **수락** / **다음에**. (오른쪽·왼쪽으로 밀어도 됨)
- 수락하면 바로 촬영(미션)으로. 끝나면 DM함으로 돌아와 다음 DM.
- 3건 수락하면 방 끝.
- 6통을 다 넘겼는데 3건이 안 찼으면 넘긴 DM이 "한 번만 다시 생각해 주세요🙏"로 돌아온다(이때 수락은 관심 점수 낮게).
- DM 문구가 곧 미션 설명이다. 그 뒤의 짧은 설명 카드 → '시작' 규칙은 그대로.

### 3-3. 촬영 — 미션
- 레거시 놀이를 그대로 쓴다. 화면 귀퉁이에 REC 표시만 더한다.
- 목숨 없음, 실패해도 다음으로 넘어간다.

### 3-4. 리뷰 — 실력
- 판이 끝나면 의뢰인 별점 ★0~3 + 댓글 한 줄 + 하트가 쏟아짐.
  - ★3 "사장님이 영상 가게에 틀어 놨대요!" / ★0 "그래도 와 주셔서 고마워요"
- 하트 수만큼 구독자가 오른다(실력의 누적 표시).

### 3-5. 방 끝 — 노리개 선물
- 그 방에서 **점수가 가장 높은 컨셉**의 의뢰인이 노리개 장식을 보낸다.
- 장식 = 컨셉 주체, 띠돈 = 그 도 문양. 화면 위 노리개 띠에 하나씩 걸린다.
- 방을 다 못 돌아도 받은 만큼은 남는다.

### 3-6. 출구 — 채널 결산
1. 구독자 수, 촬영 수, 받은 장식 줄
2. 컨셉 6개 막대 두 줄: **좋아한 것(관심)** / **잘한 것(실력)**
3. **유형 발표**: 상위 두 컨셉으로 21유형 중 하나 (6장)
4. **삼작노리개 완성**: 상위 컨셉 3개의 장식을 한 띠돈에 꿰는 연출. 술 색은 전체 별 평균
5. 저장 이미지 / QR(정하기)

## 4. 점수

| 행동 | 관심 점수 |
|---|---|
| 처음 보자마자 수락 | +3 |
| 앞에서 넘긴 뒤 같은 방에서 수락 (3건을 채우려고 다시 돌아온 DM 포함) | +1 |
| 다음에 | −1 |

실력 점수 = 별 ★0~3.
**컨셉 점수 = 관심 + 실력.** 같으면 실력이 높은 쪽.
안 본 컨셉(방을 덜 돌아서)은 0점. 숫자는 사용자 플레이테스트 후 조정.

> 판정 예: 방 하나에서 먹방 수락(+3) ★3 → 6점, 뷰티 넘김(−1), 전통 수락(+3) ★1 → 4점 … → 먹방 장식(석류) 선물.

## 5. 컨셉 6개와 노리개 장식

| 컨셉 | 이 크리에이터가 찍는 것 | 장식 | 빛깔·재료 | 장식에 담긴 뜻 |
|---|---|---|---|---|
| 뷰티 | 바르기·꾸미기·스타일링 | **향갑** | 분홍 산호 | 향을 넣어 지니던 갑 |
| 먹방 | 한입, 먹는 리액션 | **석류** | 홍옥 | 알알이 풍성 |
| 음식 | 손질·굽기·끓이기 | **방아다리** | 금 | 곡식 찧는 방아, 넉넉함 |
| 관광 | 명소·야경·축제를 보여 주기 | **나비** | 칠보 파랑 | 꽃을 찾아 날아다님 |
| 여행 | 걷기·타기·체험 | **호리병** | 비취 | 길손이 차던 물병 |
| 전통 | 민속놀이·공예·소리 | **매미** | 백옥 | 선비의 다섯 덕 |

노리개는 실제 구조대로 **띠돈 – 매듭 – 장식 – 술**.
띠돈 8종(도 문양): 전남 차잎 · 경북 첨성대 · 충청 연꽃 수막새 · 서울 성곽 · 제주 동백 · 전북 부채 · 강원 설악 봉우리 · 경남 유등
