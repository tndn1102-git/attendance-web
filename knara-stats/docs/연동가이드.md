# 「K의 나라」 연동 가이드 — 입장 페이지 · 게임 앱 · 통계 서버

대상: 게임 앱(`https://desirenvy1.duckdns.org/knara/`) 개발자와 배포 담당자.
구조: **전시장 QR → 입장 페이지(`entry/index.html`) → 게임**. 입장 페이지가 안내·동의·언어·나이대·성별을 받고 게임으로 보낸다. 게임 안에는 **스크립트 두 줄 + 흐름 지점 호출**만 넣는다(앱 안에 설문 화면을 추가할 필요 없음).

> 게임 소스는 이 문서를 쓰는 PC 에 없어 브라우저에서 관찰한 번들 기준이다. "소스에서 확인할 것" 표의 항목은 실제 소스에서 맞춘다.

---

## 1. 입장 페이지 (`entry/index.html`)

- 한 파일(HTML+CSS+JS, 의존성 없음, 폰 390px 기준). `../track.js` 를 불러 쓴다.
- 상단 `CONFIG` 에서 바꾸는 값:

| 키 | 뜻 | 기본 |
|---|---|---|
| `GAME_URL` | 게임 주소 | `/game/` (같은 워커가 서빙하는 노리개 편) |
| `CONSENT_VERSION` | 동의 문구 버전. 문구를 바꾸면 올린다(이벤트에 실림) | `v1` |
| `REQUIRE_CONSENT` | `true` 면 "동의 없이 시작" 링크를 숨겨 미동의 입장 불가 | `false` |
| `PASS_LANG_QUERY` | 게임 주소에 `?lang=ko` 를 붙여 넘김 | `true` |
| `HANDOFF_SESSION` | 게임이 다른 origin 일 때 `?sid=&s0=(&kstat=off)` 를 붙여 세션을 잇는다 | `true` |
| `RETENTION` | 안내문의 보존기간(일). `docs/데이터명세.md` 와 같아야 함 | 120 / 120 |

- **화면 문구(5개 언어 + 바닥 발주처 표기 `ORG`·문의처 `CONTACT`)** 는 같은 파일의 `<script type="application/json" id="entry-text">` 블록에 있다. 손으로 고쳐도 되고, 브라우저에서 고치려면:
  ```powershell
  cd D:\test3\knara-stats
  npm run edit-entry          # → http://localhost:5178/entry/
  ```
  글자를 클릭해 바로 고치고 **저장(Ctrl+S)** → 원본 `entry/index.html` 에 기록(백업 `data/entry-backup/`). **배포** 버튼이 `wrangler deploy` 까지 실행한다. 언어는 접속 직후 뜨는 언어 팝업(또는 바닥의 지구본 링크)으로 바꿔 가며 고친다. 팝업 안의 언어 이름(한국어·English·日本語·中文·Español)은 각 언어 고정 표기라 편집 대상이 아니다. 편집이 켜진 동안 버튼·칩은 눌리지 않는다(편집 꺼짐 = 미리보기).
  - `collect`·`no`·`why` 는 " · " 로 구분된 목록, 보관 줄의 일수는 화면에서 숫자로 직접 고치면 된다(`{E}`/`{L}` 자리표시는 남겨 둔 언어에서만 `CONFIG.RETENTION` 값으로 바뀐다). ⚠️ 실제 삭제는 자동이 아니다 — 120일 뒤 `npm run wipe -- --yes` 로 손으로 지운다. 줄바꿈은 Enter(저장 시 `<br>`), 세로 제목만 줄바꿈 없음.

- 흐름: 언어 선택 팝업(접속 직후 중앙, 5개 언어를 각자 그 언어로 표기한 네모칸) → 안내 박스 → 나이대·성별 칩(선택 안 하면 `skip`) → 동의 체크 → **시작하기**
  → `KStat.lang(lang)` · `KStat.demo({age, gender})` · `KStat.consent({agreed:true, version})` 전송 → `GAME_URL` 로 이동.
  "동의 없이 시작" → `KStat.consent({agreed:false})` 1건만 보내고 **수집 중단 플래그**(localStorage `kstat:optout`=`1`)를 켠 뒤 이동.
- 세션 id 는 입장 페이지에서 만들어진다(`track.js` 가 로드 시 `enter` 를 보냄). 게임은 이 세션을 이어받는다(§3).
- 주소 `?hl=en` 으로 초기 언어를 정할 수 있다(언어별 QR 안내판). 이때는 언어 팝업이 뜨지 않는다. `?staff` 가 있으면 스태프 세션.
- 어디에 올리나: ① 통계 서버(Cloudflare)의 `/entry/` — 기본. 수집 endpoint 가 같은 origin 이라 `KSTAT.endpoint:"/api/track"` 그대로. ② 게임 서버에 복사(`/knara/entry/`) — 이 경우 두 줄을 절대 주소로: `endpoint:"https://knara.tndn1102.workers.dev/api/track"`, `<script src="https://knara.tndn1102.workers.dev/track.js">`. 게임과 같은 origin 이 되므로 세션 인계가 자동이다(§3-A).
- 번역(en/ja/zh/es)은 ko 원문 기준 초벌이다. **파일 안 `T` 객체에 "검수 필요" 표시** — 발주처 검수 후 교체.

## 2. 게임 앱에 넣는 두 줄

`index.html` 의 `<head>` 끝(번들보다 앞):

```html
<script>
  window.KSTAT = {
    endpoint: "https://knara.tndn1102.workers.dev/api/track",
    staff: /(^|[?&#])staff/.test(location.search + location.hash),
    app_ver: "1.0.0",     // 배포마다 올리면 버전별 비교 가능
    token: ""             // 서버에 TRACK_TOKEN 을 설정한 경우만
  };
</script>
<script src="https://knara.tndn1102.workers.dev/track.js" defer></script>
```

- 로드 실패·오프라인에도 앱은 그대로 동작(모든 호출 `try/catch`). 아래 가드로 `KStat` 이 없어도 안전:
  ```js
  var KS = window.KStat || { track:function(){}, sensor:function(){}, role:function(){}, map:function(){}, fallback:function(){}, qualityDown:function(){}, allDone:function(){}, result:function(){}, room:{enter:function(){},done:function(){}}, play:{start:function(){},clear:function(){},fail:function(){},swap:function(){}} };
  ```
- Service Worker 가 있으면 `/api/track` 은 캐시 제외(네트워크 전용).
- 미동의 세션(`kstat:optout`)이면 track.js 가 스스로 아무것도 보내지 않는다 — 앱 코드에서 분기할 필요 없음.

## 3. 입장 페이지 → 게임 세션 인계

| 경우 | 방법 | 할 일 |
|---|---|---|
| **A. 같은 origin** (입장 페이지를 게임 서버 `/knara/entry/` 에 둠) | `sessionStorage["kstat:s"]`(세션 id·시작시각·순번)와 `localStorage["kstat:optout"]`(미동의 플래그)가 자동 공유 | 없음. 게임은 `?lang=` 만 읽으면 됨 |
| **B. 다른 origin** (입장 페이지는 통계 서버, 게임은 desirenvy1…) | 입장 페이지가 `GAME_URL?sid=<32hex>&s0=<ms>&lang=ko(&kstat=off)` 로 이동. 게임의 `track.js` 가 주소의 `sid/s0` 를 읽어 같은 세션으로 이어 가고, `kstat=off` 면 수집을 끈다 | 게임이 주소의 `sid`·`s0`·`kstat`·`lang` 를 **지우지 않으면** 됨(해시 라우팅이면 무관). 게임이 주소를 재작성한다면 `track.js` 가 먼저 읽도록 `<head>` 에 둔다 |

저장소 키 이름: `kstat:s`(sessionStorage, 세션) · `kstat:q`(localStorage, 전송 큐) · `kstat:optout`(localStorage, 미동의).

## 4. 게임 흐름 지점 → 호출 (관찰 함수명 기준·추정)

| # | 지점 | 호출 | 비고 |
|---|---|---|---|
| 1 | 로드 | (자동) 세션 이어받기 / 새 세션 `enter` | 입장 페이지를 거치지 않고 직접 열면 여기서 세션이 시작됨 |
| 2 | `startMotion()` 결과 | `KS.sensor("motion", "granted"\|"denied"\|"unsupported")` | iOS `requestPermission()` 결과, 안드로이드는 이벤트 수신 여부 |
| 3 | `startMic()` 결과 | `KS.sensor("mic", …)` | 박수 인식 |
| 4 | 노리개 확정 | `KS.role("idol"\|"chef"\|"creator")` | |
| 5 | 메인 지도 | `KS.map()` | |
| 6 | `selectCity()`/`enterRoom(id)` | `KS.room.enter(roomId)` | `land speech life story island field mountain sea` |
| 7 | 판 시작(오버레이 톡) | `KS.play.start({ room, slot:1\|2\|3, game:<type>, kind, role, target, limit_s })` | `limit_s` 는 실제 적용값(상수 말고 변수) |
| 8 | `win()` / `complete()` | `KS.play.clear({ hits })` | 소요시간 자동 |
| 9 | `fail()` | `KS.play.fail({ hits, reason:"timeout"\|"miss" })` | |
| 10 | 실패 후 교체 | `KS.play.swap(<새 type>)` → 새 판 `KS.play.start(...)` | |
| 11 | 도 색 획득 | `KS.room.done(roomId, <완료 도 수>)` | |
| 12 | `finish()` | `KS.allDone()` | 입장부터의 경과 = 완주 소요 |
| 13 | 결과 카드 | `KS.result()` | |
| 14 | 화질 자동 하향 | `KS.qualityDown("low", fps)` | |
| 15 | 센서 없이 끌기·톡 진행 | `KS.fallback("drag"\|"tap")` | |
| 16 | 언어 변경(게임 안에서 바꿀 수 있다면) | `KS.lang("en")` | 입장 페이지가 이미 보냈으므로 바뀔 때만 |
| 17 | WebGL 손실 · 오류 | (자동) | |

언어·나이대·성별·동의는 **입장 페이지가 보내므로 게임에서 호출하지 않는다.**

## 5. 소스에서 확인할 것

| 항목 | 왜 |
|---|---|
| 놀이 데이터의 `type` 실제 값 63개 | `lib/catalog.js` 는 번들 순서로 매핑한 추정 |
| 방 id·충북 분리 여부 | 새 id 가 생기면 카탈로그 추가 |
| 판 slot/kind 규칙(자리 섞임) | `play.start` 의 slot 의미 통일 |
| 실패 종류(timeout 외 miss 유무) | |
| 센서 권한 API 위치·안드로이드 판정 | |
| 화질 하향 단계명·조건 | `qualityDown` 첫 인자 |
| **게임이 `?lang=` 쿼리를 읽는지** | 안 읽으면 입장 페이지의 언어 선택이 게임에 안 넘어감 → 게임 언어 선택 화면이 그대로 뜨거나, 게임에 쿼리 읽기 한 줄 추가 |
| **게임이 주소 쿼리를 지우는지**(해시 라우팅·`history.replaceState`) | 다른 origin 인계(§3-B)에 영향 |
| 스태프 모드 판별식 | `window.KSTAT.staff` 식에 반영 |
| Service Worker 유무 | `/api/track` 캐시 제외 |
| `console.error` 사용량 | 잡음 방지 |
| 완주 뒤 "다시 하기" 흐름 | 2회차를 따로 세려면 `KStat.newSession()` |

## 6. 연동 후 확인 (10분)

1. 폰에서 입장 페이지를 `?staff` 로 열어 20대·여성·한국어, 동의 → 시작. 게임이 열리고 주소에 `sid=`(다른 origin 일 때) 가 붙었는지 본다.
2. 대시보드 → "스태프 포함" → 오늘: 총 방문자 +1, 동의 +1, 나이대 20대 +1, 성별 여성 +1, 언어 한국어 +1.
3. 게임에서 한 도를 끝낸다 → 놀이별 탭에 시도/성공이 찍히는지. 자세히 탭 퍼널이 단계별로 1 인지.
4. 입장 페이지에서 "동의 없이 시작" → 미동의 +1, 이후 게임 플레이가 **아무것도 기록되지 않는지**(놀이별 수치 불변).
5. 비행기 모드로 한 판 → 켬 → 30초 안에 반영(오프라인 큐).
6. 카카오톡 인앱으로 QR → 기기 탭 인앱 "카카오톡" 집계.
