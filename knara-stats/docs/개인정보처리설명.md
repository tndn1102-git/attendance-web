# 개인정보 처리 설명 — 「K의 나라」 운영 통계

발주처 검토·안내문 게재용. 결론부터: **이 통계는 개인정보를 수집하지 않도록 설계되었고, IP 주소도 저장하지 않는다.** 제안서(11장)의 약속 "웹 콘텐츠마다 같은 익명 통계를 붙여 둡니다. 개인정보와 IP는 저장하지 않습니다." 를 그대로 구현했다. 입장 페이지에서 **활용 내용을 먼저 안내하고 동의를 받은 뒤** 수집하며, 동의하지 않으면 수집하지 않는다.

## 1. 수집하는 것 / 수집하지 않는 것

| 수집하는 것 | 형태 | 목적 |
|---|---|---|
| 동의 여부·동의 문구 버전 | 동의/미동의, `v1` | 동의 기록 |
| 나이대·성별 | **구간값만**(10대/20대/…/60대 이상, 여성/남성/기타/답하지 않음). 선택 사항 | 방문자 구성 파악 |
| 선택한 언어·노리개(직업) | ko/en/ja/zh/es, idol/chef/creator | 방문자 구성·안내 개선 |
| 세션 번호 | 폰 브라우저가 무작위로 만든 32자리 값(탭을 닫으면 사라짐) | 한 사람의 플레이를 한 줄기로 묶어 완주 계산 |
| 진행 이벤트·소요 시간 | 방 입장·판 시작/성공/실패·도 완료·완주 등 | 완주율, 난이도 조정 |
| 기기 환경 | OS·브라우저·인앱 브라우저·기기 모델명(UA 파싱)·화면 크기·배율·CPU 코어 수·메모리 구간 | 화면 잘림·멈춤 환경 찾기, 저사양 대응 검증 |
| 오류 로그 | 메시지·스크립트 위치·스택 | 비정상 종료 원인 |
| 스태프 모드 여부 | 참/거짓 | 점검 플레이 분리 |

| 수집하지 않는 것 |
|---|
| 이름·전화번호·이메일·계정·생년월일(정확한 나이) |
| **IP 주소**(코드 어디에서도 읽지 않음 — `lib/ingest.js` 는 요청 헤더 중 `User-Agent` 만 참조) |
| 쿠키·광고 식별자·기기 고유 번호 |
| 정확한 위치(GPS)·카메라 영상·마이크 음성(박수 인식은 폰 안에서만 처리, 통계에는 "권한 허용/거부"만) |
| 입력한 텍스트, 사진, 결과 카드 이미지 |
| 세션을 넘어 사람을 다시 알아보는 값 |

**나이대·성별은 구간값만 받고, 세션 번호 외 어떤 값과도 결합하지 않는다.** 한 세션의 (나이대, 성별, 기기 모델) 조합만으로는 수백만 명이 같은 값을 가지므로 개인을 알아볼 수 없다. 대시보드와 CSV 는 집계(세션 수)만 보여 준다(세션 목록 CSV 에도 식별자는 없다).

## 2. 개인정보에 해당하지 않는 근거(한 줄)

「개인정보 보호법」 제2조 제1호의 개인정보는 "살아 있는 개인에 관한 정보로서 … 개인을 알아볼 수 있는 정보(다른 정보와 쉽게 결합하여 알아볼 수 있는 것 포함)" 인데, 여기서 다루는 세션 번호는 무작위이고 어떤 외부 정보(IP·계정·쿠키)와도 연결되지 않으며, 나이대·성별은 구간값이라 **특정 개인을 알아볼 수 없고, 쉽게 결합할 다른 정보도 보유하지 않는다.**

보수적으로 보더라도 「가명정보」가 아니라 처음부터 식별자가 없는 **익명 통계**에 해당한다. 그럼에도 투명성을 위해 입장 페이지에서 활용 내용을 안내하고 동의를 받는다(부록). 미동의 시 기록은 "미동의 1건"뿐이며 이후 어떤 이벤트도 전송되지 않는다(`track.js` 의 `kstat:optout` 플래그).

## 3. 안내문 문구(QR 안내판·앱 바닥용 짧은 판)

> 이 체험은 운영 개선을 위해 나이대·성별(구간)·언어·진행 단계·소요 시간·기기 종류·오류 발생 여부를 익명으로 집계합니다. 이름·연락처·IP 주소 등 개인을 알아볼 수 있는 정보는 수집하지 않습니다.

영문: *For service improvement, this experience collects anonymous statistics (age group, gender, language, progress, time spent, device type, errors). No personal information or IP address is collected.*

## 4. 보관·접근·삭제

- 저장소: Postgres 1개(Neon Free 또는 발주처 서버). 테이블 3개.
- 접근: 대시보드·집계 API 는 접속 키 필요. 수집 API 는 쓰기 전용.
- 보존: 진행 기록 400일, 오류 로그 180일 → `node scripts/purge.js`. 전시 종료 뒤 요청 시 전체 삭제(`DROP TABLE knara_*`).
- 전송: HTTPS, 제3자 분석 도구 없음.

## 5. 운영 시 지켜야 할 것
1. `KStat.track("x_…")` 자유 이벤트에 입력 텍스트·이름·전화번호를 넣지 않는다.
2. 앱이 `console.error` 에 개인 입력을 찍지 않는다.
3. 접속 키는 담당자만 보유, 유출 시 환경변수 교체로 즉시 무효.
4. 동의 문구를 바꾸면 입장 페이지 `CONSENT_VERSION` 을 올린다(어느 문구에 동의했는지 구분).
5. 발주처가 "미동의 시 입장 불가"를 원하면 `REQUIRE_CONSENT: true`.
