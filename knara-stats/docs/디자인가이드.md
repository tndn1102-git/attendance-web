## 1. 컨셉 문장과 금지 목록

**컨셉 한 문장** — "한지 위에 먹으로 찍은 물건": 손님 입장 페이지는 게임 첫 화면(한지색 종이 + 세로 명조 타이틀 + 검정 도장 버튼)의 연장이고, 운영 통계는 같은 종이에 같은 먹으로 적은 **장부(帳簿)**다. 종이(--hanji)·먹(--meok)·오방색 포인트(적·청·황·녹)·놋쇠(--brass)만으로 세계를 만들고, 3D 지도 없이도 **색·종이·글자**가 같아서 한 세계로 읽히게 한다.

| 재질 | 빛 | 글자 | 움직임 |
|---|---|---|---|
| 한지(종이 결 타일 220px) 위 반투명 흰 카드(inset 1.5px 선) | 그림자는 "밑그림자" 하나(0 4px 0 #000) — 번짐·글로우 없음 | 제목·숫자 Hahmlet(명조 굵게), 이야기 글 Gowun Batang, 표·라벨 Noto Sans KR | 눌리는 도장(translateY 3px), 이징 `cubic-bezier(.2,.8,.2,1)` 하나 |

**금지 목록 (하면 세계가 깨진다)**
1. 그라디언트·글로우·네온·블러 배경. 그림자는 `--shadow-btn`(밑그림자)·`--shadow-card`(0 2px 0) 둘만.
2. 게임 팔레트 밖의 색(보라·민트·형광). 새 톤이 필요하면 원본 색의 **명도만** 조정한 파생 토큰(`--mute-aa`, `--hwang-d`, `*-bg`)을 쓴다.
3. 장식 이모지. 아이콘은 인라인 SVG 선 아이콘(게임의 바텀시트 아이콘과 같은 1.8px 스트로크)만. 언어 알약의 지구본도 SVG.
4. 게임에 없는 전통 문양(단청·태극·구름무늬·매듭 일러스트) 지어내기. 모티프는 **색동 띠·구슬 8개·먹 도장·알약 라벨·반투명 카드·검정 도장 버튼** 여섯 가지뿐.
5. 카드 격자 반복·가운데 정렬 남발. 입장 페이지는 왼쪽 정렬 + 오른쪽 세로 타이틀의 비대칭, 대시보드는 왼쪽 정렬 표·오른쪽 정렬 숫자.
6. 대시보드에 설명문·도움말 문장 넣기(사용자 요구: 뜻풀이는 운영가이드에).
7. `--mute`(#8D8477)를 본문·작은 글자에 쓰기(한지 위 대비 3.1:1, AA 미달). 작은 글자는 `--c-ink-mute`(#6F6657, 4.9:1).
8. 한 화면에 강조 2곳 이상(놋쇠 강조는 KPI 1장, 입장은 색동 띠 1줄).

## 7. 확인 필요 사항

1. **글꼴 라이선스·로드 방식**: Hahmlet·Gowun Batang·Noto Sans KR·Nanum Brush Script 는 모두 OFL(Google Fonts). 발주처 PC 가 외부망 차단이면 `@import` 가 실패하고 폴백(맑은 고딕·바탕)으로 뜬다 — 그래도 레이아웃은 유지되지만 톤이 빠지므로, 차단 환경이면 woff2 4종을 `assets/fonts/` 에 넣고 `@font-face` 로 바꿀지 결정 필요(용량 약 1.5MB).
2. **발주처 표기**: 입장 바닥 "청와대 사랑채 · 문화체육관광부", 보고서 머리글 "청와대 사랑채 국민화합 체험형 문화 프로그램 「K의 나라」" — 확정 문구·로고 사용 가능 여부. 도장 "K" 는 임시 마크이며 공식 로고가 있으면 `.seal` 자리에 교체.
3. **세로 타이틀 외국어**: "El País K"(es)·"K-Land"(en) 는 세로로 길어진다 → E4 의 `.long`(34px) 규칙으로 처리하되, 실제 5개 언어 렌더를 구현 후 확인.
4. **인쇄 흑백 확인**: 레이저 흑백에서 ①방문(단색) vs 완주(빗금) ②도 8색 막대(이름 열로 구분) ③붉은 도장(검정 네모로 보임) 실제 출력 1회 확인. "배경 그래픽" 꺼진 기본 설정에서도 막대가 나오는지(P4).
5. **종이 결 타일**: 현재는 SVG 노이즈. 게임 앱의 실제 `--paper` 타일 이미지(220px)를 받을 수 있으면 교체해 완전히 같은 결로.
6. **지구본 아이콘**: 게임은 글리프/이모지로 보이는데 입장은 SVG 로 그렸다. 게임 쪽 아이콘 에셋을 받으면 동일 교체.
7. **대시보드 다크모드 없음** 확정 여부(공공 PC·인쇄 전제).
